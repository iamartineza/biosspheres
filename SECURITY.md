# Security policy

## Supported versions

Only the latest release of biosspheres receives fixes.

| Version | Supported |
| ------- | --------- |
| 0.2.x   | yes       |
| < 0.2   | no        |

## Reporting a vulnerability

Please do not open a public issue. Write to biosspheres@pm.me with a
description of the problem and, if possible, a minimal example that
reproduces it. We will answer within two weeks and agree with you on a
fix and on when to disclose it.

biosspheres is a numerical library that runs locally and does not handle
network input or credentials, so most problems are better reported as
ordinary bugs in the issue tracker.
